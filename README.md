# Promo incrementality (Bikky demo)

Live at https://lance06kaye-cloud.github.io/bikky/

A promo incrementality tool that runs entirely in the browser (Streamlit via
[stlite](https://github.com/whitphx/stlite)). Uploaded data stays on the visitor's
computer. All sample data is simulated.

This folder is generated by `web/build.py` in the source project; don't edit it by hand.
